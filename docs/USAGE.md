## Quick Start

### 1. Buka Aplikasi
- Cari icon "Kasir Djoeragan" di home screen
- Ketuk untuk membuka aplikasi

### 2. Dashboard (Layar Utama)

- **Total Penjualan Hari Ini** - Ringkasan penjualan

## Fitur Detil

### Tambah Produk
1. Buka menu "Produk"
2. Ketuk tombol "+" atau "Tambah Produk"
3. Isi informasi:
   - **Nama Produk** - Nama produk
   - **Deskripsi** - Keterangan produk (opsional)
   - **Harga** - Harga jual
   - **Stok** - Jumlah stok awal
   - **Gambar** - Foto produk (opsional)
4. Ketuk "Simpan"

### Proses Transaksi Penjualan
1. Buka menu "Transaksi Baru"
2. Pilih produk yang akan dijual
3. Masukkan jumlah/kuantitas
4. Produk akan ditambahkan ke keranjang
5. Ulangi step 2-4 untuk produk lainnya
6. Review detail transaksi:
   - Daftar produk
   - Subtotal
   - Diskon (jika ada)
   - Total bayar
7. Pilih metode pembayaran:
   - Tunai (Cash)
   - Kartu Kredit/Debit
   - Transfer Bank
   - Lainnya
8. Konfirmasi pembayaran
9. Cetak receipt (optional)
10. Transaksi selesai

### Laporan Penjualan
1. Buka menu "Laporan"
2. Pilih periode:
   - Harian
   - Mingguan
   - Bulanan
3. Lihat ringkasan:
   - Total penjualan
   - Jumlah transaksi
   - Produk terlaku
   - Metode pembayaran
4. Export laporan (PDF/Excel) - Coming Soon

### Kelola Stok
1. Buka menu "Produk"
2. Pilih produk yang ingin diupdate
3. Ketuk "Edit Stok"
4. Masukkan jumlah stok baru
5. Pilih tipe perubahan:
   - Penambahan (+)
   - Pengurangan (-)
   - Penyesuaian (set ke nilai tertentu)
6. Tambahkan catatan (opsional)
7. Simpan

## Tips & Trik

### Mempercepat Proses Transaksi
- Gunakan fitur pencarian produk
- Atur favorit produk yang sering dijual
- Aktifkan quick buttons untuk produk populer

### Manajemen Stok yang Baik
- Cek stok setiap hari
- Set alert untuk stok minimum
- Catat setiap perubahan stok
- Review laporan stok bulanan

### Maksimalkan Laporan
- Export laporan untuk analisis lebih lanjut
- Identifikasi trend penjualan
- Monitor produk dengan penjualan rendah
- Buat strategi promosi berdasarkan data

## Troubleshooting

### Aplikasi Crash
- Tutup aplikasi sepenuhnya
- Clear cache: Settings → Apps → Kasir Djoeragan → Storage → Clear Cache
- Buka kembali aplikasi

### Data tidak Tersimpan
- Pastikan storage device cukup ruang
- Restart aplikasi
- Cek koneksi internet (jika ada fitur cloud)

### Print Receipt Gagal
- Pastikan printer Bluetooth terhubung
- Cek koneksi Bluetooth
- Pastikan printer dalam kondisi online
- Update driver printer jika diperlukan

### Stok tidak Terubah
- Refresh layar dengan swipe down
- Pastikan perubahan sudah disimpan
- Cek apakah ada notifikasi error
